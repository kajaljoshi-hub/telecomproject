# telecomproject
# 📊 TellCo Telecom Customer Analytics

A Telecom Customer Analytics Dashboard built using **Python, Pandas, Plotly, Scikit-learn and Streamlit**.

This project analyzes customer engagement, user experience and customer satisfaction using telecom data and presents the results through an interactive dashboard.

---

## 🚀 Project Overview

The dashboard provides analysis of telecom customers across different areas:

- User Engagement Analysis
- User Experience Analysis
- User Satisfaction Analysis
- Customer Segmentation using K-Means Clustering
- Model Tracking
- Interactive Data Visualizations

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Scikit-learn
- K-Means Clustering
- StandardScaler
- Jupyter Notebook
- MLflow
